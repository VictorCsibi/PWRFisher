# PWR Fishing: ideas to make it better, more addictive and more satisfying

`[x]` = done, `[~]` = done in a simple version, `[ ]` = still to do.

Already in the game before this list: auto and manual casting, combos, daily challenges and streaks, legendary fish fights, chests and bottles,
boosts, storms, pets, titles, ranks, gems, 72+ rewards, 11 maps with ups and downs, 125 fish, the Fish Book, the sunset start screen,
clicky keyboard-style buttons, multi catches, discovery bonus, lucky 25th catch, fish of the day, and fish that really swim in the water and get hooked.

---

## 1. Make every catch feel amazing (juice)

- [x] A different catch sound for each rarity (short stingers: rare, epic, legendary, mythic).
- [x] The bucket wobbles and squishes when a fish lands.
- [x] A "+$" flies from the bucket into the money box.
- [x] The money counter rolls up (with a soft ticking sound).
- [x] A slow-motion beat when a legendary fish bites.
- [x] A little camera zoom when a fish bites.
- [x] Bigger fish make bigger splashes.
- [x] First-time fish do a victory spin above the water.
- [x] A glow around the screen edges in the rarity colour when a good fish is on the line.
- [~] The stickman reacts: he jumps for rare catches and slumps when he catches junk (no fist pump yet).
- [x] Fireworks over the map on a rank up.

## 2. Make the "one more cast" feeling stronger

- [x] "A RARE FISH IS COMING!" warning.
- [x] "3 MORE FISH FOR: ..." when a reward is close.
- [x] A golden aura around the fisherman on a catch streak.
- [x] Mystery bites (a silhouette until it lands, worth 1.5x).
- [x] Hot spots (manual mode only, in the middle of the water and always within your line's reach).
- [x] Golden Hour (x1.5 for a minute).
- [x] A red flash when a rare fish gets away.
- [x] A tournament you start yourself from the Boosts page (3 minutes against 5 anglers, with prizes and gems).

## 3. Progression

- [x] The shop shows the next upgrade and how much is missing, and glows on things you can afford.
- [x] Rod mastery stars.
- [x] Fish records in cm.
- [x] Fish Book page rewards per map, and star ratings on each Fish Book entry (1, 10 and 100 catches).
- [x] Bait crafting: junk gives scrap, fish give scales, and you craft Sweet Bait, Shiny Lure and Deep Lure.
- [x] Skill tree: 5 skills with points from ranks and every 100 fish.
- [~] Prestige 2.0: "Legend mode" (sell x2 but harder) plus the crown hat after a Legend reset.
- [~] A story: a quest board with 10 quests from 4 town characters (no full town map).

## 4. Money loop

- [x] Market prices, daily sale, fish orders.
- [x] Offline earnings from your fishing trap.
- [x] A piggy bank that fills while you play.
- [x] A restaurant that buys two kinds of fish for double for 5 minutes.
- [~] A boat tree: Rowboat, Motorboat and Yacht (each +5% luck and reel speed).

## 5. Manual mode

- [x] Perfect throw, last-landing ring, wind.
- [x] A perfect-reel timing bar near the end of the reel, and perfect throw + perfect reel gives x1.6.
- [x] Line tension: heavy fish (size 5+) pull in manual mode. Hold to reel, let go when the tension bar gets tight, or the line snaps.

## 6. World variety

- [x] Junk can hide treasure or a gem.
- [x] Night fish (9 kinds only bite at night).
- [x] Boss fish (a huge red-ringed fish appears now and then: x3 value, gems and a charm).
- [~] Map events: a whale swims by (rarer fish) and diving birds (faster bites).
- [~] Seasons: snow, spring petals, summer sparkles or autumn leaves depending on the month, with +5% sell value.
- [x] A 30-second dive mini-game (click the shells and pearls).
- [x] Four new maps: Neon Harbour, Sky Lake, Candy Lagoon and Ancient Ruins (15 maps now, each with its own ups and downs).
- [x] More weather: fog (3x more mystery bites), a rainbow after the rain (+10% sell) and northern lights on cold and sky maps at night.

## 7. Collecting and looks

- [x] Pets react to catches and level up.
- [x] Rod skins (Golden, Frosty, Fiery, Neon), hats (achievement hats and gem hats) and dock decorations, all bought with gems.
- [x] A photo button (Boosts page) and the C key.
- [x] Lucky charms (6 of them, found in chests, junk, epic fish and boss fish).

## 8. Rewards, gems and surprises

- [x] Daily spin, mystery box, gems that fly to the counter, weekly challenges, gem shop for cosmetics.

## 9. Sound

- [x] Rarity stingers, a coin tick, bird chirps on green maps, a combo that climbs a little scale.
- [x] Music gets a driving beat in fights and big combos, and every map has its own track feel (neon, sky, candy, ruins, cold, dark).

## 10. Polish

- [x] Pause (P), tooltips, tutorial, statistics, skip-intro option.
- [x] Colour-blind colours option, performance mode button, save code export and import (Settings).
- [x] Touch friendly buttons and no page scrolling on the game canvas.
- [x] Installable app (a web app manifest and an offline service worker).

## 11. Balance and fairness checks
